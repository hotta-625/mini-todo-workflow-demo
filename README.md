# ミニ ToDo — 開発ワークフローの練習

これは ChatGPT / Codex / GitHub / Vercel / Google Drive の流れを一度体験するための、依存関係のない小さなWebアプリです。

## 動かし方

`index.html` をブラウザで開くだけで使えます。

## 開発の流れ

1. 要件の正本: Google Drive の「ミニToDoアプリ：開発の流れ（サンプル）」
2. 実装タスク: GitHub Issue
3. コード変更: feature ブランチ → Pull Request
4. 動作確認: Vercel Preview
5. 公開: main ブランチへマージ

## 次回 Codex に頼む例

> Issue #番号を実装してください。READMEとdocs/requirements.mdを読み、完了条件を満たすことを確認してください。変更後に、確認した内容をPR本文にまとめてください。

## 公開の確認

GitHub の `main` ブランチに変更を送ると、Vercel が自動で本番公開します。
